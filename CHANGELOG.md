# Історія змін

## 2.0.1

- Невдалий перехід на API v1 зберігає останній валідний кадр і час.
- Маски цифр читаються до заміни кадру; порожні маски й невидимі кольори відхиляються.
- Зміна сервера вимагає іншого ключа; неоднозначні HTTP IPv4 з початковими нулями відхиляються.
- Універсальна область службового часу в межах екрана: підтримано його початкове
  розташування угорі праворуч та розташування в паперовому чеку.
- Перевірка фону під усіма цифрами до прийняття кадру, для RLE й raw RGB565.
- Еталон початкового дизайну генерується старим C++-кодом для точного порівняння
  із серверною «Класичною», без додавання логіки окремих тем у прошивку.

## 2.0.0

- Універсальний приймач серверних тем: перевірені RGB565-кадри, RLE та атлас цифр.
- Локальний час останнього успішного оновлення з червоним кольором після помилки.
- Перевірка SHA-256, CRC, розмірів і меж перед прийняттям кадру; збереження
  попереднього зображення після пошкодженої або неповної відповіді.
- Новий кадр записується у flash лише після зміни; синхронізація працює під час сну.
- Налаштування джерела API для локальних тестів, підтвердження джерела після
  переходу зі старої прошивки та сумісність із резервним API v1.
- Автоматичні перевірки контракту кадрів і діагностичний експорт екрана.

## 1.2.0

- Нічний сон із повністю вимкненими ST7789 і підсвіткою; пробудження на початку дня.
- Повідомлення про сон після нічного ввімкнення; обмежене очікування часу після
  втрати живлення, потім темний екран до синхронізації без припущень про час.
- Сон/пробудження без Wi-Fi при збереженому годиннику; відновлення задач після
  пробудження, оновлення розкладу й OTA під час сну.
- Локальний повний розклад та вибір джерела параметрів: ця плата або Напотім.
- Тести півночі, втрати часу/живлення, офлайн-пробудження, DST та rollover.

## 1.1.6

- Час останнього оновлення змінюється посимвольно, без проміжного стирання.
  Напис `Оновлено` та незмінені символи не перемальовуються, зокрема під час
  зміни дати чи лічильників задач. Зміна кольору охоплює лише час.
- Виправлено сторонній відтінок фону цифр: режим шрифту та колір фону
  в буфері задаються явно після вибору шрифту.

## 1.1.5

- Підказки прив'язки оновлено до **Налаштування → Інтеграції**.
- Підготовлено публічний репозиторій, інструкцію та автоматичну збірку.

## 1.1.4

- Дата по центру, `Оновлено HH:MM` праворуч.
- Після невдалого оновлення червоним стає лише час, до наступного успіху.
- Нижній рядок відведений для непоказаних задач.

## 1.1.3

- Wi-Fi/NTP стартують до підготовки дисплея та завантаження налаштувань.
- Прибрані повторні очищення екрана й зайве очікування після остаточного EOF.
- Додані заміри етапів запуску й отримання даних.

## 1.1.1

- Перший запит одразу після готовності Wi-Fi/часу, startup retry через 3 секунди.
- Стани мережі, часу, запиту та повтору показуються окремо.

## 1.1.0

- Яскравість, розклад і поворот налаштовуються з Напотім.
- Кешуються параметри й переходи локального часу; перехід яскравості — 15 хвилин.

## 1.0.x

- Шість статичних рядків, пріоритети, категорії й дедлайни.
- HTTPS validation, перевірка повноти відповідей, шрифти у flash.
- Native Misc Fixed 7×14, поліпшений контраст категорій і прострочених задач.
