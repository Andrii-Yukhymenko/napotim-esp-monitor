# Технічні деталі

## Обладнання

GeekMagic SmallTV-Ultra: ESP8266 / ESP-12F, 4 МБ flash, ST7789 240×240.
CPU 160 МГц, апаратний SPI; повноекранного framebuffer немає.

| Сигнал | GPIO |
| --- | --- |
| SCLK | 14 |
| MOSI | 13 |
| CS | 15 |
| DC | 0 |
| RESET | 2 |
| Підсвітка, active-low | 5 |

Типовий поворот — 2 (180°), ручна яскравість — 22%.
Повороти 0–3 відповідають 0°, 90°, 180° та 270°.

## API та збереження

Wi-Fi зберігає ESP SDK; ключ і параметри дисплея — LittleFS `/config.json`
із записом через тимчасовий файл. Локальні налаштування й OTA використовують
HTTP Digest, користувач `admin`. Локальний HTTP-сервер призначений для домашньої мережі.

Read-only HTTPS GET: `/api/device/v1/today`, заголовок
`Authorization: Bearer <device-key>`. Сертифікат і hostname перевіряються через
ISRG Root X1. NTP: `time.cloudflare.com` і `pool.ntp.org`.

Схема відповіді — `schema_version: 1`; необхідні `generated_at`, `date`,
`utc_offset_seconds`, `items`, `total`, `hidden_count`, `today_total`, `overdue_total`.
До шести `items`, тіло до 6144 байт із Content-Length. Некоректні й неповні
відповіді відхиляються. HTTP 401/403 очищає прив'язку та задачі; інші помилки
зберігають останній список до успішного оновлення.

До першого успіху повтор — через 3 секунди після невдалого запиту. Після успіху
інтервал — 60 секунд; подальші мережеві помилки збільшують паузу до 120, 240
і максимум 300 секунд. Відновлення Wi-Fi запускає запит одразу.
Мережеві/body timeouts — 15 секунд. Остаточний EOF завершує читання негайно;
буферизовані TLS-записи дочитуються навіть після закриття TCP.

## Налаштування дисплея

`display_settings` у відповіді задає режим, яскравість 1–100%, поворот,
денний/нічний рівень і локальний час початку. Перехід займає 15 хвилин;
початки розділені щонайменше 15 хвилинами, включно з переходом через північ.
Налаштування з Напотім замінюють локальні зміни після синхронізації.

Кешуються UTC offset і до чотирьох майбутніх переходів часу. Після втрати
живлення до NTP використовується ручна яскравість: ESP8266 не має годинника
з резервним живленням. Налаштування зберігаються лише коли змінюються.

## Пам'ять та діагностика

`include/font_flash.h` переносить U8g2 у flash із `pgm_read_byte`, звільняючи
приблизно 9 КБ RAM. BearSSL: receive buffer 16 КБ, transmit buffer 512 байт.
Заголовки задач — native Misc Fixed 7×14, крок 7 пікселів.

Час `Оновлено HH:MM` кешується посимвольно. Змінений символ спершу
малюється з фоном у буфері 6×12 RGB565 (144 байти на стеку), а потім
передається на ST7789 однією SPI-транзакцією, без окремого очищення комірки.
Зміна кольору перемальовує всі символи часу, але не напис `Оновлено`.
Оновлення дати/лічильників не очищає цю частину заголовка; після очищення
всього екрана або повороту статус малюється повністю.

- `/health` — назва й версія, без авторизації.
- `/status` — HTTP Digest: Wi-Fi/RSSI, clock readiness, видимі/приховані задачі,
  `update_stale`, HTTP/TLS/body errors, останній успіх, параметри, heap, uptime.
- `timing` — готовність мережі й часу, перший запит та успішний показ від
  запуску, тривалість HTTP, body, cleanup, validation/render і всього запиту, у мс.

Діагностика не повертає ключів, паролів і тексту задач. RTC trace не записує
flash під час кожного запиту. Етапи: 1 readiness, 2 TLS client, 3 trust anchor,
4 HTTPS GET, 5 response, 6 JSON validation, 7 rendering, 0 idle.

## Додатковий loader

Fallback лише для заводського слота, який не вміщує головний образ.
На перевіреному Ultra-V9.0.54 було достатньо gzip головної прошивки.

Створіть локальний `include/private_wifi.h`, виключений із Git:

```cpp
#define PRIVATE_WIFI_SSID "your-network"
#define PRIVATE_WIFI_PASSWORD "your-password"
#define PRIVATE_LOADER_PASSWORD "a-unique-temporary-password"
```

Зберіть `pio run -e loader`, встановіть loader і через його `/update` одразу
встановіть головний `firmware.bin`. Образ loader містить пароль Wi-Fi й
призначений лише для власного пристрою. Головна прошивка цього файла не потребує.
Опційний `include/private_setup.h` задає `PRIVATE_SETUP_PASSWORD` для приватної
збірки; публічні образи збираються без нього.
